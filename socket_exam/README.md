# 소켓 프로그래밍 단계별 예제

Windows의 Winsock으로 TCP 소켓 프로그래밍을 단계별로 익히는 C 예제입니다. 간단한 에코 서버에서 시작해, 여러 클라이언트를 동시에 처리하고 직접 정한 메시지 형식으로 통신하는 계산 서버까지 만듭니다.

개념 설명은 위키의 [TCP 소켓 프로그래밍](https://github.com/hansei-it/class_c/wiki/TCP-%EC%86%8C%EC%BC%93-%ED%94%84%EB%A1%9C%EA%B7%B8%EB%9E%98%EB%B0%8D) 페이지를 참고하세요.

## 학습 순서

| 단계 | 폴더 | 내용 |
|---|---|---|
| 1 | `step1_single_echo` | 소켓 함수의 호출 순서를 익힙니다. 메시지를 한 번 주고받고 종료합니다. |
| 2 | `step2_echo_loop` | 연결이 끊길 때까지 메시지를 반복해서 돌려보내고, 오류 처리를 추가합니다. |
| 3 | `step3_robust_echo` | `send()`가 데이터를 일부만 보내는 경우를 처리합니다. |
| 4 준비 | `step4_0_thread_basics` | 소켓 없이 스레드 사용법을 익힙니다. |
| 4 | `step4_thread_echo` | 스레드로 여러 클라이언트를 동시에 처리합니다. |
| 5 준비 | `step5_0_data_basics` | 소켓 없이 바이트 순서, 구조체 패딩, 직렬화를 익힙니다. |
| 5 | `step5_fixed_message` | 계산 서버를 고정 길이 메시지로 구현합니다. |
| 6 | `step6_variable_message` | 계산 서버를 가변 길이 메시지(헤더와 본문)로 구현합니다. |

5, 6단계의 메시지 형식은 각 폴더의 `protocol.h`에 설명되어 있습니다.

## 실행 방법

Visual Studio에 **C++를 사용한 데스크톱 개발** 워크로드가 설치되어 있어야 합니다.

1. 서버와 클라이언트는 프로젝트가 따로 있으므로 `server/server.sln`과 `client/client.sln`을 각각 다른 Visual Studio 창에서 엽니다.
2. 서버를 먼저 실행(Ctrl+F5)한 뒤 클라이언트를 실행합니다. 서버와 클라이언트는 같은 PC에서 `127.0.0.1:9001`로 통신합니다.
3. 4단계부터는 클라이언트를 여러 개 실행해 동시 접속을 확인해 보세요.

`step4_0_thread_basics`와 `step5_0_data_basics`는 프로그램이 하나뿐이므로 폴더의 `.sln`만 열어 실행합니다.

## 종료 방법

| 단계 | 서버 | 클라이언트 |
|---|---|---|
| 1 | 자동 종료 | 자동 종료 |
| 2, 3 | 클라이언트 연결이 끊기면 자동 종료 | `exit` 입력 |
| 4 | Ctrl+C | `exit` 입력 |
| 5, 6 | Ctrl+C | 메뉴에서 `0` 입력 |
